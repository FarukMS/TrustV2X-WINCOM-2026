Paper-ready interpretation
--------------------------------------------------------------------------------
The controlled SUMO experiment demonstrates the upper-bound performance of TrustV2X under a fully controlled C-ITS/V2X simulation environment. The external VeReMi Extension benchmark provides a more challenging validation setting. The results show that TrustV2X engineered temporal, mobility and plausibility features substantially outperform raw BSM/CAM-like fields, especially under vehicle-disjoint evaluation. This supports the claim that TrustV2X improves misbehavior detection generalisation beyond the internally generated SUMO dataset.


Important limitations to state
--------------------------------------------------------------------------------
The VeReMi labels were derived by comparing received trace messages with ground-truth physical states using position, speed, acceleration and heading error thresholds. These ground-truth error columns were used only for label construction and audit, not as model input features. The results should therefore be framed as simulation and benchmark-based validation, not direct real-road deployment evidence.
