4. Paper-ready interpretation
--------------------------------------------------------------------------------
The best overall VeReMi vehicle-disjoint result was achieved by XGBoost using VeReMi_TrustV2X_No_Rule_Flags, with accuracy=0.9636, recall=0.9854, F1=0.9692, false alarm rate=0.0667, and MCC=0.9254.
The strongest deep learning result was obtained by MLP using VeReMi_TrustV2X_Full, with accuracy=0.9608, recall=0.9650, F1=0.9664, false alarm rate=0.0451, and MCC=0.9193. This shows that the MLP is competitive with the strongest tree-based models on the message-level VeReMi benchmark.
The best raw BSM/CAM-like baseline achieved only F1=0.6765 and FAR=0.6754 under vehicle-disjoint validation. This confirms that raw message attributes alone generalise poorly compared with TrustV2X temporal, mobility and plausibility-aware features.
The best 1D-CNN result achieved only F1=0.2320 under vehicle-disjoint validation. Therefore, 1D-CNN should be reported as tested but not selected. Its poor generalisation is attributed to the message-level tabular representation, where neighbouring feature columns do not form a true temporal sequence.


5. Final recommendation for the paper
--------------------------------------------------------------------------------
The paper should prioritise F1-score, recall/detection rate, false alarm rate, MCC and latency. Accuracy should be included in result tables for completeness, but should not be used as the headline interpretation metric. The final selected model should be XGBoost with TrustV2X No Rule Flags. The final selected deep learning model should be MLP with TrustV2X Full. LSTM should be excluded because a fair LSTM experiment requires explicit vehicle-level temporal windows.
